# zybclean

作业帮（`com.zuoyebang.knowledge`）净化模块，适配 14.34.0 (1738)。

- 去广告：拦截广告聚合层 `com.fastad` 的加载与展示，屏蔽开屏 / 激励视频等广告页
- 去首页信息流与「科普专区」，隐藏首页搜索框、通知铃铛、红点角标与绑定账号推广卡
- 屏蔽 AI 解题页，注入 JS 隐藏结果页 H5 里的 AI 解题 tab 与「讲解中」浮窗
- 去 H5 解答页的视频会员推广：「本题精讲 / 考点讲解视频 / 相关视频」整块卡片与底部会员横幅（按真实 class 名匹配，不看文字）
- 去「历史记录」页贴底的「高效学习，一个VIP就够了」金色横幅（按视图几何定位，全宽贴底即可命中）
- 解答页：隐藏底栏「问小帮」，解除复制限制（可自由选中/长按复制），右侧浮出「复制内容 / 存题目 / 存解答 / 下载图片」按钮
  - 复制内容：整页题目与解答进剪贴板（公式按 tex 还原，不再混入隐藏 tab 与内联脚本）
  - 存题目 / 存解答：按题目与解答的分界把整页切成两张 PNG（各存一份，用户自己选），撑开整页一次画完，公式与排版原样保留，存 `Pictures/zybclean`；落笔前再清一次复活出来的视频卡与推广条
  - 下载图片：保存页面里全部可见图片到 `Pictures/zybclean`
- 开屏提速

不重打包原 APK，不收集任何数据。
