# zybclean

作业帮（`com.zuoyebang.knowledge`）净化模块，适配 14.34.0 (1738)。

- 去广告：拦截广告聚合层 `com.fastad` 的加载与展示，屏蔽开屏 / 激励视频等广告页
- 去首页信息流与「科普专区」，隐藏首页搜索框、通知铃铛、红点角标与绑定账号推广卡
- 屏蔽 AI 解题页，注入 JS 隐藏结果页 H5 里的 AI 解题 tab 与「讲解中」浮窗
- 解答页：隐藏底栏「问小帮」，解除复制限制（可自由选中/长按复制），右侧浮出「复制内容 / 存长图 / 下载图片」按钮
  - 复制内容：整页题目与解答进剪贴板（公式按 tex 还原，不再混入隐藏 tab 与内联脚本）
  - 存长图：把渲染后的整页截成一张 PNG（撑开整页一次画完，不滚动拼接，无接缝/重复），公式与排版原样保留，存 `Pictures/zybclean`；截图前自动剔除视频讲解卡与广告条
  - 下载图片：保存页面里全部可见图片到 `Pictures/zybclean`
- 开屏提速

不重打包原 APK，不收集任何数据。

源码、详细说明与反馈：https://github.com/SQL0106/zuoyebang_xposed
